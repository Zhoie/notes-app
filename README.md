# notes-app

React application built with Vite.

Use the patched Node.js version in `.nvmrc`, then run `npm ci`.

- `npm start`: run the development server on port 3000.
- `npm run build`: generate the production site in `build/`.
- `npm run preview`: serve the production build locally.

The application routes, styles, and React components are preserved. Vite replaces the retired Create React App build chain and its vulnerable development dependencies.
